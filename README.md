# 果园保卫战

原创果子精灵主题的浏览器生存游戏。控制英雄躲避虫群，自动射击、拾取经验并选择随机升级；站定后提升火力。

## 开始游戏

下载完整仓库，保留文件结构，打开 `index.html` 即可游玩，无需安装依赖。

填写守护者名字和密码进入游戏。新名字支持1～7个汉字、字母、数字或下划线，第一次登录自动注册，名字同时作为账号和昵称。旧版账号、昵称和存档继续兼容。

关卡账号及进度保存在当前浏览器的本地存储中，各账号独立保存。登录游戏后会自动使用同一名字和密码连接世界，城池、物资、小队和公会进度由服务器保存，不再另设世界登录表单。如果旧世界曾设置不同密码，只需验证一次原世界密码，把原家园连接到游戏账号，既有建筑、军队和物资都会保留。服务器只保存密码校验值；用于自动重连的登录凭证仅留在当前页面内存，退出游戏即清除。

登录后，在首页选择“开始引导”进入“晨芽练习场”。十步实操依次教授移动、站定蓄力、自动攻击、经验拾取、随机升级、英雄技能、饰品领取、投放图、精英怪和Boss；完成后可以查看英雄、装备、果园与无尽模式等功能介绍。练习提供生命保护，可随时退出或重练，不消耗材料、不发放正式关卡奖励。

## 当前玩法

升级需求采用平滑递增曲线：前五级为140、197、262、335、416经验，前期较快成长、中后期逐步放慢。秒数不是固定倒计时，仍需击杀并拾取经验；正式关卡仅设置2.5～8秒的短防连弹窗口，等待期间经验保留、暂停与菜单不计时。新手教学仍需180经验，无尽沿用新的经验曲线。

正式关卡的后续虫群随实战时间增加血量与接触伤害，在第一次追击/登场时锁定，不给已经交战的怪物突然回血。前三关强化更温和，所有正式关卡有倍率上限；移速不增加，无尽保留原有按波次强化。

精英与Boss轮盘显示真实词条名称、图标和品质，固定指针对应抽中奖励，转动结束后展示收获卡片；精英单抽、Boss三连抽，构筑已满转为生命补给。

- 100个具名关卡、5大篇章；后80关复用20种地形主题，镜像布局和独立障碍种子，配套碰撞与饰品地图。
- 13位初始解锁英雄及专属技能，普通怪、精英怪与按独立实战时间登场、可同时在场的Boss。
- 50种特殊饰品，每局随机投放6种，拾取后获得相应技能或属性效果。
- 32种局内词条、攻击与属性两类构筑、8个超级技能配方。
- 每关精确提供10,000点经验及30次升级；前期升级节奏已放慢。通关后可以进入无尽模式，突破构筑上限。
- 装备、30级英雄训练、15～20级全队研究、果园建设及获救精灵培养；封面登录、新手引导、游戏内开发对话快照。
- 100关首通分别救援100位精灵，10座果园各住10位，按关卡每10关分区。果园共享10级扩建，精灵各自培养至5级；21～100关新精灵的单级祝福为初始同类型精灵的一半。老存档按已通关关卡补齐精灵，保留原培养等级和材料，重复通关不会重复救援。
- 共享世界：通关领取世界专属木材、石料、粮草、铁矿与世界令；选地建家、返回主城查看八种建筑、手动收取生产物资、训练步兵/弓兵/骑兵并编组最多三支小队、加入公会、捐献与攻打其他玩家家园。多人资源、军队与战报由服务器保存和结算。

电脑使用WASD或方向键移动，E施放英雄技能，M打开投放图，H查看引导与对话，P或Esc暂停，1/2/3选择升级。手机按住场地拖动。

详细数值和说明见 `试玩说明.txt`、`100关与英雄养成说明.txt`（原前20关详表见 `20关数值表.txt`）、`局内构筑与超级技能说明.txt` 等文件。

## 钻石商业化原型（免费测试充值）

不再直接卖加属性的晨露护符。现在的完整链路为：点击顶部钻石余额旁的「＋」→选择180/600/1800钻石免费测试充值→进入钻石商城→使用钻石购买商品。

- 星辉守护光环：240钻石，永久外观，购买后自动装备，角色脚下显示光环；不增加战斗属性。
- 丰收头像框：120钻石，永久外观，购买后自动装备，战斗英雄头像显示金色边框；不增加战斗属性。
- 阳光补给礼包：60钻石，发放180阳光籽，可重复购买。
- 果核补给礼包：90钻石，发放6果核，可重复购买。

余额不足不发货也不扣钻；重复购买已拥有外观不扣钻。外观可以免费装备或取消装备。一次交易的扣钻、发货和测试记录一并保存，存档失败则整体回滚；已处理界面的旧点击回调不能重复执行。钻石、外观和最近20条测试记录按此浏览器的登录账号保存，刷新后保留，账号之间隔离。

购买、装备与测试充值均原地更新余额和商品状态，不重绘整个窗口、不重置滚动或焦点；充值后保留在充值页，手动切换商城。成功或失败提示固定显示在底部，便于连续购买。

商城与充值期间冻结战斗，不重置本局HP、经验、技能、敌人或Boss时间。外观不提供生命或拾取加成；新手教学不开放商业化入口。补给只发放现有养成材料，不改变当前战斗属性。

当前是免费测试商业化流程：充值不花真钱，但买商品实际消耗钻石。这不是云端钱包或真实付费凭证，不生成支付订单、不调用支付接口；换浏览器或清理存储可能丢失。未来真实收费需要另接服务端订单、支付回调、余额与商品权益校验，不能信任本地commerce字段。

## Boss 独立登场时间

所有正式关卡首只 Boss 固定在实战 60 秒登场；上一只尚未击败也不推迟下一只。第4～20关间隔由42秒逐步降到30秒，第21～100关由36秒逐步降到30秒。清空小怪或击杀Boss都不改变时间表；暂停、升级、轮盘与菜单冻结实战时间。前三关各只有一只Boss。

例如第4关为60/102/144/186秒；第10关每38秒一只，第20关每30秒一只、最后一只630秒；第40关每35秒一只、最后一只375秒；第100关每30秒一只、最后一只330秒。仍需击败全部普通怪、精英及Boss才结算。

## 验证

安装Node.js后，可以运行以下离线逻辑检查：

```sh
node verify.cjs
node auth-verify.cjs
node login-integration-verify.cjs
node experience-verify.cjs
node upgrade-pacing-verify.cjs
node time-pressure-verify.cjs
node boss-timing-verify.cjs
node store-verify.cjs
```

经验及时间压力详表见 `经验升级数值表.txt`，可用 `node tools/update-experience-table.cjs` 从当前代码重新生成。

其余 `*-verify.cjs` 文件分别验证地形、美术、寻路、饰品、成长和战斗等模块。美术原文件、网页资源及生成提示词均保存在 `assets/` 中。

## 共享世界服务与测试工具

双击 HTML 可以游玩本地关卡；多人世界需要先启动服务，再从该服务地址打开游戏。Python 服务只使用标准库，SQLite 保存世界账号、地图、公会与战报。登录游戏并连接世界后，再挑战正式关卡，通关后服务器发放独立物资；新手练习与无尽模式不发放世界物资。局外点击「回到主城」可以直接进入自己的建筑区，收取物资或打造小队；尚未建家时先从世界地图选择空地。

```sh
python3 tools/world-server.py --host 127.0.0.1 --port 8765 --db .world-server-data/world.sqlite --site .
```

本地游戏地址为 `http://127.0.0.1:8765/index.html`，沿用这个地址可以保留原浏览器的关卡账号和进度。若该端口已有旧静态预览，请先停止旧服务。局域网或公网联机需通过同源代理接入这个服务；详细规则、生产配置与部署脚本见 `世界玩法说明.txt`、`tools/WORLD-SERVER.md`。浏览器报告关卡胜利，服务端验证奖励票据、时间和领取频率，当前版本没有完整的服务端关卡战斗反作弊。

```sh
python3 tools/world-server-verify.py
node frontier-ui-verify.cjs
node frontier-rewards-verify.cjs
```

`tools/` 还包含受限的 HTTP 入口检查和临时 SQLite 容量模型。容量模型不能代替实际服务验收；HTTP 工具只发送短时 HEAD 请求。

```sh
node tools/http-capacity-check.cjs http://你的服务器地址/
python3 tools/world-capacity-bench.py
python3 tools/world-capacity-bench-verify.py
```

仅对自己的服务器或获授权的测试环境运行容量检查。本仓库不包含服务器登录凭据、浏览器账号数据或另一仓库的历史恢复备份。
