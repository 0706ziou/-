# 果园保卫战

原创果子精灵主题的浏览器生存游戏。控制英雄躲避虫群，自动射击、拾取经验并选择随机升级；站定后提升火力。

## 开始游戏

下载完整仓库，保留文件结构，打开 `index.html` 即可游玩，无需安装依赖。

填写守护者名字和密码进入游戏。新名字支持1～7个汉字、字母、数字或下划线，第一次登录自动注册，名字同时作为账号和昵称。旧版账号、昵称和存档继续兼容。

账号及进度保存在当前浏览器的本地存储中，各账号独立保存。当前版本没有云端账号或跨设备存档。

## 当前玩法

- 20个具名关卡及独立地形、美术、碰撞和饰品投放地图。
- 8位初始解锁英雄及专属技能，普通怪、精英怪与按时间逐只登场的Boss。
- 50种特殊饰品，每局随机投放6种，拾取后获得相应技能或属性效果。
- 32种局内词条、攻击与属性两类构筑、8个超级技能配方。
- 每关精确提供13,046点经验及40次升级；前期升级节奏已放慢。通关后可以进入无尽模式，突破构筑上限。
- 装备、英雄训练、果园建设及获救精灵培养；封面登录、新手引导、游戏内开发对话快照。

电脑使用WASD或方向键移动，E施放英雄技能，M打开投放图，H查看引导与对话，P或Esc暂停，1/2/3选择升级。手机按住场地拖动。

详细数值和说明见 `试玩说明.txt`、`20关数值表.txt`、`局内构筑与超级技能说明.txt` 等文件。

## 验证

安装Node.js后，可以运行以下离线逻辑检查：

```sh
node verify.cjs
node auth-verify.cjs
node login-integration-verify.cjs
node experience-verify.cjs
```

其余 `*-verify.cjs` 文件分别验证地形、美术、寻路、饰品、成长和战斗等模块。美术原文件、网页资源及生成提示词均保存在 `assets/` 中。

## 服务器测试工具

`tools/` 包含受限的HTTP入口检查和临时SQLite世界读写模型。Python工具只使用标准库与临时测试数据库，HTTP工具只发送短时HEAD请求。模型结果用于初步评估，需要与实际联网服务端复测；它们没有实现真人世界、公会或攻城服务。

```sh
node tools/http-capacity-check.cjs http://你的服务器地址/
python3 tools/world-capacity-bench.py
python3 tools/world-capacity-bench-verify.py
```

仅对自己的服务器或获授权的测试环境运行容量检查。本仓库不包含服务器登录凭据、浏览器账号数据或另一仓库的历史恢复备份。
